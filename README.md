 1. Ваши «задачи» будут объектами, которые вы захотите динамически создавать, что означает использование фабрик или конструкторов/классов для их генерации.
    Каждая такая задача — это отдельный объект с какими-то свойствами (название, статус — выполнена или нет и т.д.).  
  
- *function createTask(title) {return {title: title, done: false};} / class Task {constructor(title) {this.title = title; this.done = false;}}*

 2. Проведите мозговой штурм, какие свойства будут у ваших todo-элементов. Как минимум, они должны иметь title, description, dueDateи priority. Вы также можете захотеть включить notes или даже checklist.

- *Название, описание, срок выполнения, важность задачи, заметки, календарь.*

 3. Проект по умолчанию. Когда пользователь открывает приложение в первый раз, создается один основной проект.

- *Экземпляр класса по типу: основная задача, работа, поход в магаз и т.д.*

 4. Разделить логику на модули.

- *src/module/script1.js, script2.js, script3.js/*

 5. Внешний вид пользовательского интерфейса

- *Сортировка, выпадающий список, подсветка важных задач, редактирование, создание задачи, удаление задачи, и т.д.*
